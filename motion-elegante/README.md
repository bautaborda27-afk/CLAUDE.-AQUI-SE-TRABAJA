# Motion elegante — proyectos

Videos hechos con la habilidad `motion-elegante` (`.claude/skills/motion-elegante/`).

- `marcas/<marca>/brand.json` — identidad de cada cliente (colores, tipografías, logo).
- `<proyecto>/spec.json` — guion de escenas. Se regenera con:
  `python3 ../.claude/skills/motion-elegante/scripts/build.py <proyecto>/spec.json`
- `output/` — videos finales renderizados.

Demos: `demo-savinghub` (vertical, oscuro, Reels) y `demo-atelier` (horizontal, claro, YouTube).
